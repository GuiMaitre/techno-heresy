# Instructions for assistants working in this project

When the user asks to install or set up Techno-Heresy, follow [SETUP_WITH_AI.md](SETUP_WITH_AI.md). The user obtains game data; this project never downloads it. Preserve the ignored `data/` and `.rag-cache/` folders as local-only files. For rules and army questions after setup, use the skills in `.agents/skills/` and cite installed local sources. Never claim installed data is current beyond the dates shown by those sources.
